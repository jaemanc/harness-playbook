# harness-playbook

AI 에이전트와 바이브 코딩 세션이 참조하는 범용 엔지니어링 지침 모음입니다.

## 목적

여러 에이전트나 코딩 도구가 작업할 때 일관되게 따를 수 있는 **범용 지침**을 한곳에 모아 관리합니다. 특정 프로젝트나 스택에 종속되지 않고, 어디서든 재사용할 수 있는 원칙만 담습니다.

## 구성

| 파일 | 내용 |
|---|---|
| `code-level-guide.md` | 코드 작성·수정 시 지킬 원칙 |
| `test-level-guide.md` | 테스트와 검증에 대한 원칙 |
| `infra-level-guide.md` | 인프라·IaC 작업에 대한 원칙 |
| `agent-coding-guide.md` | 에이전트의 전반적인 코딩 행동 원칙 |

## 사용 방법

각 가이드 파일을 에이전트의 컨텍스트나 규칙(rules)에 포함시켜 참조합니다. 프로젝트별 세부 규칙은 이 지침 위에 덧붙여 사용합니다.

## 원칙

- 범용적으로 적용 가능한 지침만 작성합니다.
- 특정 언어·프레임워크·프로젝트에 종속된 내용은 넣지 않습니다.
